Table type — fixing the cells & the zero

Headings stay Archivo. These four vary the cell font (the client names) and the figure font for IDs & currency. Every option here uses a clean, un-dotted, un-slashed zero — the top strip blows the digits up so you can check the 0 shape directly.

My pick: Option A — drop the monospace entirely. A proportional sans with tabular figures (à la Stripe / Mercury) keeps currency columns aligned, kills the code-y zero, and makes client names feel less generic.
