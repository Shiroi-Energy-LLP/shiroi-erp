Compositional table primitives. Wrap rows in `Table` › `TableHeader`/`TableBody` › `TableRow` › `TableHead`/`TableCell`. The header is warm near-black (`n-900`) with uppercase Archivo labels; rows are 44px with zebra striping and a gold selected state (`data-state="selected"`). Right-align numeric columns. Use `stickyHeader` on long list pages so the header freezes to the page scroll.
