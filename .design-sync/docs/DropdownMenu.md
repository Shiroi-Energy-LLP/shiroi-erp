Action menu anchored to a trigger. Compose `DropdownMenu` › `DropdownMenuTrigger` (often `asChild` on a ghost Button) + `DropdownMenuContent` with `DropdownMenuLabel`, `DropdownMenuItem`s, and `DropdownMenuSeparator`. Use for row actions (View / Edit BOM / Archive) and overflow menus.
