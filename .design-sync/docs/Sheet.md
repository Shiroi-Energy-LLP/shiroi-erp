Slide-over panel anchored to an edge (`side="right"` default; also `left`/`top`/`bottom`). Compose `Sheet` › `SheetTrigger` + `SheetContent` (`SheetHeader` › `SheetTitle` + `SheetDescription`, body, `SheetFooter`). Use for filters, detail edits, and secondary flows that shouldn't leave the current page.
