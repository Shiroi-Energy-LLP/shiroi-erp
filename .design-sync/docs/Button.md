Primary action control. `variant="default"` is the solar-gold fill with dark ink — the main call to action. Use `solar` for a brighter marigold CTA, `outline`/`ghost` for secondary actions, `destructive` for delete/irreversible actions, and `link` for inline text actions. Sizes: `sm`, `default`, `lg`, `icon`. Set `asChild` to render the styles onto a child (e.g. an `<a>`).
