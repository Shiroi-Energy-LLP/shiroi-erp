Status pill. Use the fixed status vocabulary so the same state always reads the same: `success` (Commissioned/Paid), `pending` (Awaiting/Draft), `warning` (In progress/Delayed), `error`/`destructive` (Fault/Overdue), `info` (Net metered), `neutral` (Archived). `default` is the solar-gold brand badge; `secondary`/`outline` for non-status labels.
