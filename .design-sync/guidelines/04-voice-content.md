# Voice & content

Shiroi ERP is an internal work tool for an Indian solar business. The voice is **plain, specific, and operational** — never marketing-flavoured inside the app.

- **Tone:** calm, factual, task-focused. State what is true and what to do next. No exclamation, no hype, no cleverness.
- **Person:** second person for actions ("Retry from Vendor Bills", "Approve this proposal"); neutral for system state ("Sync failed — 2 invoices rejected"). The dashboard greets by first name ("Good morning, Vivek").
- **Casing:** sentence case for everything readable — headings, buttons, descriptions. UPPERCASE only for eyebrow/section labels and table-header cells.
- **Specificity over generic:** empty states name the entity and the action — *"No proposals yet → Create your first proposal"*, never "No data found". KPIs carry a quantifying sub-note ("8 active proposals").
- **Numbers & domain language:** Indian numbering throughout — ₹ with lakh/crore (`₹12,45,000`, `₹12.45 L`, `₹1.24 Cr`). Power `kW`/`MW`, energy `kWh`/`MWh`, CO₂ in tonnes. Dates `DD MMM YYYY` (21 Mar 2025) or relative ("3 days ago"); times 12-hour IST. Domain nouns used precisely: net metering, DISCOM/TNEB, AMC, BOM, BOQ, commissioning, PM, O&M, milestone.
- **Status words are fixed:** Active/Commissioned/Paid = green · Awaiting/Draft = amber · In progress/Delayed = orange · Fault/Overdue = red · Net metered/Syncing = blue · Archived = grey.
- **No emoji.** Functional Unicode marks only (✓ ▲ ▼ → ⌘K).

Example microcopy: *"Payroll export due in 3 days."* · *"Viewing as: Designer — Back to Founder View"* · *"No leads yet → Add your first lead."*

## The lifecycle this ERP serves
Sales Engineer → Designer → Closure → PM (BOM) → Purchase Officer → Execution → Site Supervisor (daily reports) → QC & Commissioning → O&M Technician. Eleven roles (founder, sales, designer, PM, purchase, supervisor, O&M tech, finance, HR, marketing, customer). It exists to solve: cash invisibility, slow manual quoting, knowledge trapped in phones, no O&M tracking, error-prone HR/payroll.
